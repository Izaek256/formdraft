# ADR-0013: Golden test policy

- Status: Proposed
- Date: 2026-10-09
- Source: FR-021, NFR-014
- Requirements: FR-021; FR-023; FR-041; NFR-014

## Context

A golden test generated by the code it tests proves nothing about fit or correctness.

## Decision

Golden fixtures come from the verified hand drafts and the book's worked example, entered by a person. They are never produced by the implementation under test. Updating a fixture needs a human decision and a changelog entry in tests/fixtures/CHANGELOG.md. Snapshot auto-update modes are not used. Tolerances come from the G0 sign-off (OQ-17) and live in one data file.

## Consequences

Some tests cannot be written until DOM-01 finishes. Slices S05 to S07 are marked blocked until then.

## Alternatives considered

Snapshot tests that record current output were rejected: they freeze bugs.

## Revisit when

The pattern maker changes a reference draft.
