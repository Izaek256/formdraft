# Domain data

Holds the human-owned material that drives the rulebook.

- G0_Rule_Register_Aldrich_4e.xlsx: the rule register, thresholds, size charts, reference draft list, grade tables, decisions and G0 sign-off. Filled by the pattern maker and lead developer from the 4th edition.
- reference-drafts/: scans or photos of the ten hand-drafted reference skirts (REF-01 to REF-10), added during DOM-01.
- g0-signoff.md: the exported sign-off record.

Rules:

1. Only people edit the workbook. An agent reads it and never fills in constants, interpretations or verification fields.
2. The workbook holds structure, page references and the numbers a person transcribed. Do not paste the book's text or figures into the repository.
3. The status Verified, the verifier name and the date are set only by the named verifier.
4. Fixtures derived from this data are entered by a person (ADR-0013).
